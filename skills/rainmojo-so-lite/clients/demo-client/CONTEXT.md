# ศัพท์กลางของลูกค้า

คำที่ลูกค้า ทีมงาน และ AI ต้องเข้าใจตรงกัน เพราะคำเดียวกันตีความได้หลายแบบ ทุกคำมีความหมาย สิ่งที่ไม่ได้หมายถึง
ตัวอย่างที่ถูก คำที่ห้ามใช้แทน เจ้าของคำ และวันที่ตกลง ถ้าเจอคำที่ไม่อยู่ในตารางแต่ตีความได้สองแบบ ถามก่อนเขียน
