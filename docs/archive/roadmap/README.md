# คลังงานเสร็จ — rainmojo-so-lite

งานที่ปิดแล้วย้ายมาที่นี่จาก [แผนงาน](../../operations/roadmap.md) พร้อมหมวด วันที่เริ่ม วันที่ปิด
ชั่วโมงจริง โทเคนที่ใช้ และ PR แถวที่ย้ายมาแล้วไม่แก้ย้อนหลัง

หัวตารางของคลัง หมวดอยู่ต่อจาก ID เหมือนในแผนงาน (เจ้าของสั่ง 2026-10-17, DDK-481):

| ID | หมวด | งาน | เริ่ม | ปิดเมื่อ | ชม. (แผน) | ชม. (จริง) | โทเคน | PR |
|---|---|---|---|---|---:|---:|---:|---|

งานเก่าของปลั๊กอินนี้ใช้รหัส `DP-` และอยู่ใน PR เดิม, CHANGELOG และ git log ตามเดิม
